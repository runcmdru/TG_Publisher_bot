# 🚗 Telegram-бот для автопубликации контента в канал

**Эвакуатор-бот** — это удобный Telegram-бот на Python (Aiogram 3.x),  
предназначенный для автоматической публикации сообщений, изображений,  
видео, аудио и голосовых в Telegram-канал.

---

## ⚙️ Возможности

✅ **Публикация любого контента:**
- 💬 Текстовые сообщения  
- 🖼 Фото и альбомы  
- 🎥 Видео  
- 🎵 Аудиофайлы  
- 🎙 Голосовые сообщения  

✅ **Автоматическое форматирование**
- Перед каждым постом добавляется фирменный префикс  
- После текста — футер с контактами и ссылкой на сайт  
- Под каждым постом кнопки “Позвонить” и “WhatsApp”

✅ **Управление историей публикаций**
- `/queue` — показывает список всех опубликованных постов  
- `/clear` — очищает историю  

✅ **Ограничения и безопасность**
- 🔐 Доступ только для разрешённых пользователей (`ALLOWED_USERS`)
- ⏳ Не более **1 публикации в минуту**
- 🛡 Автоматическое уведомление администратора о любых ошибках
- 🔒 Проверка прав перед публикацией в канал

✅ **Удобное взаимодействие**
- `/start` — приветствие и краткая инструкция  
- `/help` — справка по функционалу  
- Интерактивная кнопка «🔙 Назад»  

---

## 🧩 Технические особенности

- **Фреймворк:** Aiogram 3.22.0 (асинхронная архитектура)  
- **Язык:** Python 3.13  
- **Хранение истории:** JSON-файл (`posts.json`)  
- **Поддержка Markdown-разметки** в текстах постов  
- **Middleware** для фильтрации пользователей  
- **Rate-Limit** для предотвращения спама  
- **.env-конфигурация** для токена и ID канала

## 📦 Установка и запуск

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/yourusername/evakuator-bot.git
   cd evakuator-bot
   ```

2. Создай виртуальное окружение и активируй его:
   ```bash
   python -m venv venv
   source venv/bin/activate   # macOS / Linux
   venv\Scripts\activate      # Windows
   ```

3. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создай файл `.env` в корне проекта:
   ```bash
   BOT_TOKEN=1234567890:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
   CHANNEL_ID=@your_channel_username
   PHONE=+79857661422
   ALLOWED_USERS=528885082,5500054868
   ```

5. Запусти бота:
   ```bash
   python bot.py
   ```

## ⚠️ Замечания

- Бот должен быть добавлен в канал **в роли администратора**  
  с правом *публиковать сообщения*.
- Telegram может блокировать частые публикации — соблюдай лимит.
- Для локальной отладки можно временно изменить `CHANNEL_ID`
  на свой личный чат ID.
